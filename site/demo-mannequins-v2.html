Page d’essai, séparée du site : le moteur et les fiches ne sont pas modifiés. Cinq styles de joueur, animés avec les mêmes poses que le site. Changez de mouvement avec les boutons du haut, puis dites-moi le style préféré (ou un mélange).

Comparatif

Les cinq styles sont dessinés dans les mêmes repères que le moteur du site (un repère par segment : bras, avant-bras, cuisse, tibia, pied, buste, tête). La description détaillée pour la conversion est dans chantiers/mannequins_v2/styles.md.
